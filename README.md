# Hecho Pa'Mí - Proyecto JavaScript

Este es un proyecto básico en **JavaScript** basado en mi emprendimiento personal **Hecho Pa'Mí**, un pequeño ecommerce en desarrollo.  
El objetivo es practicar conceptos iniciales de programación y estructura de páginas web mientras voy adaptando la idea de mi tienda online.

## 🛠️ Tecnologías utilizadas
- HTML  
- CSS  
- JavaScript  

## 📄 Descripción
El proyecto incluye funcionalidades básicas para una página web, como elementos interactivos y estructura general pensada para un ecommerce.  
A medida que avance, se irán agregando nuevas secciones y funciones relacionadas con la tienda.

## 💡 Objetivo
Aprender y practicar JavaScript mientras desarrollo una versión inicial de la web de **Hecho Pa'Mí**.
